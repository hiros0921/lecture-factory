# 参照音声の録り方（ボイスクローン用）

60〜90秒。**原稿は読まない。** これを見ながら、目の前の人に話しかけるつもりで喋る。

---

## 1. 録る前の30秒

- 空調・換気扇・冷蔵庫の近くを避ける。窓は閉める
- iPhone は口から **20cm**（手を伸ばした距離ではなく、顔のすぐ前）
- **設定 → ボイスメモ → 音質 → ロスレス** にしておく
  （圧縮された音でクローンすると、そのぶん再現度が落ちる）
- 通知を切る（集中モード）
- 録音ボタンを押したら **2秒黙ってから** 話し始める

## 2. 話す内容（各15秒 × 4つ）

キーワードだけ見て、自分の言葉で話す。噛んでも言い直せばいい。

### ① 自己紹介（15秒）

- 名前・会社名
- どんな仕事をしているか
- 何年くらいやっているか

> 言い出しの例：「株式会社ライテックの諏訪と申します。ふだんは──」

### ② 最近あった具体的な出来事（15秒）

- ここ1週間であった、仕事でも私生活でもいい出来事をひとつ
- **時系列で** 話す（「先週◯◯があって、それで──」）

抽象的な話より、具体的な出来事の方が声が自然に動きます。

### ③ 仕事で大事にしていること（20秒）

- お客さんによく言っていること
- なぜそう思うようになったか

ここは**講義に近いトーン**で。この動画で一番使われる話し方なので、
少し丁寧め・少しゆっくりめに。

### ④ 問いかけ（10秒）

**語尾が上がる疑問形を2つ以上**入れてください。

> 例：「みなさんは、動画の編集にどれくらい時間をかけていますか？」
> 　　「もし、それが十分の一になるとしたら、どうでしょう？」

これが無いと、クローンが疑問形の抑揚を再現できません。
（パイプラインは平板な疑問形を不良として検出するので、ここは重要です）

## 3. やらないこと

- ❌ 原稿を読む（読み上げ口調がそのままクローンされる）
- ❌ 声を作る・アナウンサー風にする（普段の声でいい）
- ❌ わざと笑う、「え〜」を意識的に入れる
- ❌ 途中で音量や距離を変える
- ❌ 早口で詰め込む（60秒に収めようと焦らない。90秒までOK）

## 4. 録り終えたら

- **2〜3テイク録ってください。** 一番自然だったものを選びます
- 聞き返して、雑音（車・エアコン・机を叩く音）が入っていないか確認
- AirDrop で Mac に送る

置き場所：

```
~/Desktop/zed/lecture-factory/assets/voice/
```

ファイル名は何でも構いません（`reference_1.m4a` など）。
このフォルダは `.gitignore` 済みで、Git にも配布物にも入りません。

置いたら「置きました」と一言ください。こちらで前処理（ノイズ除去・音量正規化・
無音カット）をして、**処理前と処理後の両方を残して聴き比べられるように**します。
